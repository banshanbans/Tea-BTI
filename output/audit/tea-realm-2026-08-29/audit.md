# Tea Realm《雾里一芽》PRD 一致性审计

审计时间：2026-08-29  
视口：390 × 844  
环境：本地 Web + API 当前运行版本

## 结论

当前实现已经跑通“进入茶境 → 七幕互动 → 白毫标本 → Passport/黔南点亮”的完整纵向流程，服务端进度、重玩、指针降级和完成写入也已接上。它可以作为 Demo 展示，但还不能称为与 PRD 完全一致。

如果一定要量化，整体约为 **70% 一致**：流程与状态较完整，核心手势、真实事实锚点和部分视觉转场仍明显简化。

## 当前流程

1. **茶境首页与封面｜健康**  
   《雾里一芽》入口、黔南点亮状态、白毫标本与重新体验入口均可见；封面具备沉浸感。390px 视口下，首页底部导航会遮住卡片底部与操作区域。  
   证据：[茶境首页](00-realm-home.png) · [章节封面](01-cover.png)

2. **Scene 0 从茶汤进入雾境｜部分符合**  
   点击进入和“轻触茶汤”可推进，但首帧已经是雾山背景，没有呈现 PRD 要求的茶汤涟漪逐渐转成山间雾气。  
   证据：[Scene 0](02-scene0-liquor.png)

3. **Scene 1 拨雾见山｜基本符合**  
   拖拽拨雾、桌面/传感器失败回退、键盘操作与进度反馈都可用。当前画面缺少动作完成后关于多雾山地与风味来源的事实承接。  
   证据：[Scene 1](03-scene1-mist.png)

4. **Scene 2 摘下一芽｜部分符合**  
   四选一、温和错误提示、正确后的 `1 / 53,000+` 均已实现。当前是图标卡点击，不是“从真实茶树中选择并上提一芽一叶”；也没有承担事实证明的一芽一叶真实视觉锚点。  
   证据：[Scene 2 错误反馈](04-scene2-wrong-bud.png)

5. **Scene 3 一口锅｜部分符合**  
   杀青、揉捻、搓团、提毫四个术语会在交互后出现，符合“先动作、后术语”。但四步实际共用同一种通用拖动/键盘输入，没有形成倾斜、推揉、画圆、双指摩擦四种可感知差异；声音也只是提示音，不是风、锅与叶片的氛围声。  
   证据：[Scene 3](06-scene3-craft.png)

6. **Scene 4 人的经验｜基本符合**  
   没有固定倒计时，用户可以继续试手或自主停下；过早停手会得到温和反馈。成熟度变化后，页面仍同时保留旧的“还有一点青气”提示，造成状态文案冲突。  
   证据：[Scene 4](07-scene4-judgment.png)

7. **Scene 5 回到真实｜部分符合**  
   使用了有署名、许可和 DOI 证据链的真实都匀毛尖图，且未伪造用户原话。当前展示是一条论文分级样本图，不是单一、清晰的真实干茶特写；从风格化叶片到真实干茶的过渡也不明显，成品感不足。  
   证据：[Scene 5](08-scene5-real-tea.png)

8. **Scene 6 收进 Passport｜健康**  
   白毫标本、完成页、查看茶护照与回到茶境均可用，完成后黔南点亮和标本状态能在茶境首页看到。  
   证据：[Scene 6](09-scene6-specimen.png) · [完成页](10-complete.png)

## 与 PRD 的主要差距

### 高优先级

1. 补齐 Scene 0 的“茶汤涟漪 → 雾层 → 山境”转场。
2. Scene 2 改为真实一芽一叶锚点，并增加上提/采摘动作，不再用抽象图标承担事实展示。
3. Scene 3 将四道工序拆成四种可辨识手势及各自反馈，而不是同一拖动动作换文案。
4. Scene 5 换成一张清晰、授权明确的都匀毛尖干茶特写，并做真正的风格化到真实 Reveal。

### 中优先级

1. 补回每次动作与“味道从哪里来”的短事实文案，尤其是拨雾见山和锅内工序。
2. 清理 Scene 4 的旧提示残留。
3. 修复茶境首页底部导航遮挡。
4. 在真实设备上单独计时；本次审计不能证明首次正常操作已稳定控制在 45–60 秒。

## 事实与素材边界

- 当前只有真实干茶 Reveal 具备纪录性素材属性。
- 雾层、山体、工坊和白毫标本是 Demo 生成资产，Manifest 已标注为 `synthetic_demo / demo_only`。
- 因此 PRD 要求的茶汤、一芽一叶、炒茶动作、都匀产区等真实锚点尚未全部满足。
- 茶境流程未请求摄像头或麦克风，也没有声称识别现实中的叶片、锅温或用户动作。

## 审计边界

本报告基于本次运行中对 390 × 844 页面流程的逐幕操作、截图和当前源码/资产清单检查。没有在本次审计中完成 iOS 真机方向权限、WebKit 兼容性与 45–60 秒人工计时验证。
